# Job-Application-Tracker
##About:
A beginner-friendly Python project that helps job seekers organize and track their job applications.

##Features:
1.Add job applications
2.View all applications
3.Search by company name
4.Update application status
5.Delete application
6.view job search summary
7.store data using CSV files

##Technologies used:
1.Python
2.CSV
3.File Handling
4.Exception Handling

##How to run:
1.Install python 3.
2.Download or clone this repository.
3.open a teriminal in the project folder
4.Run: python job_tracker.py
##Future improvements:
1.Add a graphical user interface
2.Store data using SQLite
3.Add interview dates and notes
4.Export application reports
