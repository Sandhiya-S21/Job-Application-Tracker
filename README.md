# Job-Application-Tracker

## About
A beginner-friendly Python command-line project that helps job seekers organize and track their job applications.

## Features
1. Add job applications
2. View all applications
3. Search by company name
4. Update application status (Applied, Interview, Selected, Rejected)
5. Delete applications
6. View job search summary
7. Store data using CSV files

## Technologies Used
- Python 3
- CSV
- File Handling
- Exception Handling

## How to Run
1. Install Python 3.
2. Download or clone this repository.
3. Open a terminal in the project folder.
4. Run:
   ```bash
   python job_tracker.py
   ```
